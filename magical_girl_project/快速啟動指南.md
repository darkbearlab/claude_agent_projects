# 快速啟動指南

*當你開啟 Claude Code 開始這個專案時的第一步指南。*

---

## 給使用者：如何開始

1. 把整個 `magical_girl_project/` 目錄放進你的 Claude Code 工作目錄
2. 開始對話時，先告訴 Claude Code：

```
請讀取 README.md、agent指令/GM.md、世界觀核心/ 底下所有檔案，
然後告訴我目前專案狀態，並建議下一步該做什麼。
```

3. Claude Code（GM）會回報並提案。常見的下一步可能包括：
   - 跑團探索「哈娜為什麼自願入伍」
   - 跑團探索「伊斯拉菲爾何時關閉自己」
   - 編劇統籌第一章
   - 補完待定的角色（日本魔法少女組合成員、名字、組合名）

---

## 給 GM（Claude Code 主對話）：每次啟動的標準流程

1. **讀取核心文件**（必做）：
   - `README.md`
   - `agent指令/GM.md`
   - `世界觀核心/world_bible.md`
   - `世界觀核心/narrative_priority.md`
   - `世界觀核心/story_skeleton.md`

2. **檢查當前進度**：
   - 看 `story_skeleton.md` 的「當前進度」與「GM 工作日誌」
   - 看哪些章節已完成、哪些待補

3. **確認待補完問題**：
   - 看 `story_skeleton.md` 末尾的待補完問題清單
   - 哪些是繼續推進前必須先解決的

4. **向使用者提案**：
   - 不要直接動工。先告訴使用者目前狀態，並提出 2-3 個可能的下一步選項
   - 等使用者選擇後再開始

---

## 常見指令範例

| 使用者說 | GM 該做的 |
|---------|----------|
| 「推進第 1 章」 | 編劇統籌模式，處理第一章 |
| 「跑團：哈娜為什麼入伍」 | 跑團模式，召喚哈娜 agent 探索 |
| 「現在第 3 章是什麼狀態」 | 讀 story_skeleton.md 回報 |
| 「給伊斯拉菲爾取一個新名字」 | 提供 3-5 個候選並說明含義 |
| 「我覺得這段哈娜會這樣說...」 | 接受使用者調整，更新狀態檔 |
| 「先看一下整個故事到目前為止」 | 讀所有已完成的章節劇本與大綱，給摘要 |

---

## 容易忘記的事

- 每次召喚角色 agent 前，**讀她的 state.md**
- 每次場景結束後，**更新她的 state.md**
- 場景內的對話記錄要**完整傳給每一個被召喚的角色**
- 產出後，**更新 story_skeleton.md 的進度與日誌**
- 遇到角色 agent 給出意料之外的反應，**先接受、再評估**——這是這個系統的價值所在

---

## 預期的 token 消耗模式

這個系統會大量消耗 token，因為：

1. 每次召喚角色 agent，都要傳入完整的人設、狀態、場景記錄
2. 每個場景可能召喚 5-20 次 agent
3. 每次工作階段結束要更新多個檔案
4. 整理產出時還要再讀一遍

這正是設計目的——讓每個場景都有「所有人都聽到彼此 + 有記憶」的感覺。
